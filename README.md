## Dependencies

This library has some fundamental dependencies which are required to use it as intended. These libraries must be provided by the consumer:

```
npm i vue@latest@3.5
npm i bootstrap@5.3
npm install vue-i18n@11
```

Those dependencies need to be imported into your
app and be exposed on the window object.
